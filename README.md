## 二、快速开始（3步上手）

### 第1步：启停系统

#### macOS / Linux

```bash
sh start_web.sh    # 前台运行
sh start_web.sh -d # 后台运行
sh stop_web.sh     # 停止
```

#### Windows

```shell
start_web.bat   # 启动。
stop_web.bat    # 停止
```

启动成功后，浏览器自动打开 http://localhost:5678

---

### 第2步：配置公众号

1. **登录系统**：默认账号 `admin`，密码 `123456`
2. **添加公众号**：
   - 进入「系统配置 → 账号管理」
   - 点击「+新增账号」
   - 填写公众号信息（AppID、AppSecret、作者名等）

> 💡 **如何获取 AppID 和 AppSecret？**
> - 登录微信公众平台：https://mp.weixin.qq.com
> - 进入「设置与开发 → 开发接口管理」
> - 获取 AppID 和 AppSecret

---

### 第3步：配置 AI

AI 配置不是必须的，但强烈建议配置，因为 AI 生成的文章质量远高于模板。

1. **进入 AI 大模型管理**：
   
   - 进入「系统配置 → AI 大模型管理」
   - 点击「+ 新增模型」
   
2. **选择 AI 提供商**（任选其一）：

   **推荐：DeepSeek（性价比最高）**
   ```
   提供商：deepseek
   模型名称：deepseek-chat
   API Key：sk-xxxxxxxxxx
   API Base：https://api.deepseek.com
   ```

   **其他选择：OpenAI / 通义千问 / Moonshot**
   ```
   提供商：openai / qwen / moonshot
   模型名称：gpt-4 / qwen-max / moonshot-v1
   API Key：对应平台的 API Key
   API Base：对应平台的 API 地址
   ```

---

### 完成！开始使用

现在你可以：
- ✅ 点击「工作台 -> 全自动发布」：5分钟生成并推送文章
- ✅ 设置定时任务：每天自动生成内容
- ✅ 自动选题：精准控制每一篇内容

> 💡 **提示**：不配置 AI 也可以使用系统，会使用内置模板生成文章，不过效果没有 AI 生成的好。

### 环境要求

- Python 3.8+
- 操作系统：macOS / Linux / Windows
- 微信公众号：已认证的订阅号或服务号

## 四、常见问题（FAQ）

### 安装和启动问题

**Q: Windows 双击 `start_web.bat` 闪退？**  
A: 右键点击 `start_web.bat`，选择「以管理员身份运行」；或者在命令提示符中 `cd` 到项目目录后手动运行 `start_web.bat`，这样可以看到完整报错信息。

**Q: Windows 提示「Python 不是内部或外部命令」？**  
A: Python 未加入 PATH。重新安装 Python 时勾选 **「Add Python to PATH」**，或手动将 Python 安装目录添加到系统环境变量。

**Q: Windows 命令行中文显示乱码？**  
A: 在命令提示符中运行 `chcp 65001` 切换为 UTF-8 编码，或使用 Windows Terminal。`start_web.bat` 已自动处理此问题。

**Q: macOS 提示权限被拒绝？**  
A: 运行 `chmod +x start_web.sh` 和 `chmod +x stop_web.sh` 给脚本添加执行权限。

---

### 配置和使用问题

**Q: 提示 `access_token` 获取失败？**  
A: 在 Web 界面「系统配置 → 账号管理」中检查 AppID 和 AppSecret 是否正确，确认公众号已开通微信认证，并且服务器 IP 已在微信公众号 IP 白名单中。

**Q: AI 写出来的文章还是有 AI 味儿？**  
A: 在账号配置中的「写作提示词」字段添加更具体的要求，或者换用能力更强的模型（如 DeepSeek-V3）。内置的「写作专家风格」已包含去 AI 味儿指令。

**Q: 选题抓取为空？**  
A: 网络问题可能导致抓取失败，尝试刷新重试，或检查网络是否能访问 IT之家等科技媒体。

**Q: 封面图中文乱码？**  
A: 系统缺少中文字体，程序会自动 fallback 到系统字体，或在 `cover_generator.py` 中手动指定字体路径。

### 功能相关问题

**Q: 多篇文章自动生成功能如何使用？**  
A: 在 Web 界面点击「⚡全自动发布」按钮或设置定时任务，系统会自动根据 AI 评分生成 1-3 篇文章。需要配置 AI 才能使用评分功能。

**Q: 定时任务串行和并行执行有什么区别？**  
A: 串行执行是多个任务依次完成，日志清晰但不重叠；并行执行是同时运行，速度快但可能日志混乱。推荐使用串行执行。

**Q: AI 生成的文章可以直接发布吗？**  
A: 建议人工审核后再发布。虽然系统内置了去 AI 味儿指令，但人工检查可以避免错误和敏感内容。

### 数据和安全问题

**Q: 如何备份数据？**  
A: 备份 `.cache/users.db` 数据库文件即可，包含所有用户、账号、文章等数据。建议每周备份一次。

**Q: 如何重置系统？**  
A: 删除 `.cache/users.db` 数据库文件，重启服务后会自动创建新的数据库，默认管理员账号为 admin/123456。

**Q: 数据安全吗？会泄露吗？**  
A: 系统完全本地化部署，数据存储在你自己的电脑上，不会上传到任何第三方服务器。AI 调用仅发送提示词和生成内容，不会存储你的数据。

**Q: 可以多人协作吗？**  
A: 可以。系统支持多用户登录，每个用户只能访问自己的数据。可以通过权限控制实现团队协作。
