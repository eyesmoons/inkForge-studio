# 比亚迪掀桌子了：十万块的海狮05，让加油站和充电桩都慌了

这两年，比亚迪的新车像下饺子一样往外冒。

海洋网，王朝网，名字起得挺热闹，但看多了，真有点麻木了。每次看到新车预告，心里头第一反应往往是：哦，又是秦的兄弟？还是宋的亲戚？换了个壳，调了点配置，又来收割一波。这种想法，我猜不止我一个人有。

直到昨天，2026款海狮05的价格和参数甩出来，我盯着屏幕愣了好几秒。

<span style="color: rgb(202,88,99); font-weight: bold;" >它不是在修修补补，它是在掀桌子。</span>

DM-i版本，9.79万起。EV版本，11.99万起。这个价格本身，已经够狠了。但真正让我后背发凉的，是它塞进去的东西。

先说那个插混版。综合续航2105公里。这个数字，我反复确认了三遍。不是1200，不是1500，是2105。这意味着什么？如果你生活在一个三线城市，每天通勤30公里，加满这一箱油，配上家充桩，你真的可以开上半年不去加油站。

它的纯电续航，是305公里。注意，这不是NEDC，是CLTC。就算打个八折，也有240公里以上。绝大多数人一周的通勤距离，完全覆盖。平时它就是一台纯电车。只有当你需要跨越半个中国时，它才需要加油。

百公里亏电油耗3.1升。比很多A0级的小车还低。技术层面，第五代DM，更大的电池包（34.275度），一切都在为“极致效率”服务。它把“省”这个字，做到了一个近乎变态的程度。

再看纯电版。630公里续航。这个数字在15万级别里，不算惊世骇俗。但配合它的“闪充”技术，9分钟补能核心电量，焦虑感被极大稀释。你不再需要为那最后50公里续航斤斤计较，服务区喝杯咖啡的功夫，电就够你跑到下一个城市。

<span style="color: rgb(202,88,99); font-weight: bold;" >这已经不是简单的产品迭代，这是一场针对用户所有痛点的精准爆破。</span>

# 你以为它只卷续航？错了

如果只是续航长，那顶多算个“偏科生”。海狮05可怕的地方在于，它是个“六边形战士”，而且是在10万出头的价位上。

外观内饰的升级，属于常规操作。新的海洋美学前脸，更协调。海贝粉和珊瑚橙的配色，明显是冲着年轻用户去的。尺寸加大，轴距拉到2770毫米，后排空间不再是短板。这些，是看得见的“面子”。

真正的“里子”，藏在下面。

云辇-C智能阻尼车身控制系统。这个名字，以前只出现在比亚迪20万甚至更贵的车型上。现在，它下放到了海狮05的高配版本。配合后四连杆独立悬架，带来的改变是颠覆性的。

过去很多人吐槽比亚迪某些车型底盘松散，像开船。云辇-C的加入，让底盘有了“韧性”。过坎时是干脆的“砰砰”两声，而不是零碎的“哐啷”一片。车身姿态抑制得更好，高速变线更有信心。这是一种质感的飞跃，从“够用”到“好开”的飞跃。

对于EV版本，后置后驱布局，iTAC 2.0智能扭矩控制，5.9秒破百。这已经是在提供驾驶乐趣了。一台十万出头的SUV，跟你谈操控，谈加速，这在几年前是不可想象的。

# 最狠的一刀，砍在智能化上

如果说底盘和驾驶质感是“补课”，那在智能化上，海狮05就是在“超车”，甚至是“降维打击”。

天神之眼高阶智能驾驶辅助系统。城市领航，高速领航，这些功能开始逐渐普及，但通常都是20万元以上车型的专属。

海狮05提供了天神之眼B激光雷达的选装方案。

<span style="color: rgb(202,88,99); font-weight: bold;" >把激光雷达和高阶智驾的选项，放到一台起售价不到10万的车上。</span>

这意味着什么？这意味着比亚迪正在用规模优势，把曾经高不可攀的尖端配置，迅速拉入寻常百姓家。它不是在试探，而是在宣告：智能驾驶的门槛，我来重新定义。

这会给竞争对手带来巨大的压力。你跟不跟？不跟，产品力被碾压。跟，成本如何控制？利润从哪里来？

还有那些细节上的用心。EV版110升的前备箱，能放一个登机箱。可选装的智能冷暖冰箱，夏天冰饮料，冬天热牛奶。电子怀挡腾出的中控台下方的巨大空间，做成储物格。这些看似微小的设计，叠加在一起，就是极强的家庭用车实用性和幸福感。

它清楚地知道买这个价位车的用户需要什么：要省，要空间，要可靠，现在，还要一点科技和质感。

# 海狮05到底在打谁？

9.79万到14.59万的价格区间。这个市场，是国内竞争最惨烈、销量最大的市场。

它首先冲击的，是同价位的燃油SUV。本田XR-V、丰田卡罗拉锐放、大众探歌这些老牌劲旅。跟海狮05比，它们的油耗、智能化、用车成本，几乎全面落后。唯一的优势，可能只剩下那个车标带来的“心理安全感”。但在真金白银的节省和越级的体验面前，这种安全感还能维持多久？

其次，是其他的国产混动和纯电车型。包括比亚迪自家的宋Pro、元PLUS。海狮05用更新的技术平台，更极致的续航，以及下放的越级配置（如云辇-C、激光雷达选装），形成了明显的代差优势。它可能会造成严重的“内卷”，逼迫自家兄弟和友商更快地更新换代。

最后，它甚至在侵蚀传统A级轿车的市场。12万左右，你是买一台卡罗拉、轩逸，还是买一台空间更大、油耗极低、还能纯电行驶的SUV？这个选择题，会越来越难做。

<span style="color: rgb(202,88,99); font-weight: bold;" >海狮05的出现，像一条凶猛的鲶鱼，它搅动的不是单一市场，而是整个10-15万价位段的生态。</span>

# 我们该怎么选？

文章开头那份摘要里的建议很中肯，我完全赞同。

如果你有家充桩，活动范围基本在市区和周边，极少有单程超过500公里的长途需求。那么，闭眼上630公里续航的EV版。用车成本低到发指，驾驶感受安静平顺，动力响应直接。它就是一台完美的城市通勤利器。

如果你的车是家庭唯一用车，需要兼顾每日通勤和节假日可能的长途跋涉。那么，305公里纯电续航的DM-i版本几乎是唯一解。日常通勤用电，每公里成本几分钱。长假出游用油，没有充电焦虑，油耗还低得惊人。它完美解决了“里程焦虑”和“成本焦虑”这两个核心矛盾。

至于配置，我的建议是，预算允许的情况下，尽量考虑高配。云辇-C带来的底盘质感提升，是后期很难通过改装获得的。而高阶智驾的选装，则代表了未来几年汽车进化的方向，值得投资。

# 最后说两句

看完海狮05，我那种对比亚迪的“审美疲劳”瞬间消失了。取而代之的是一种兴奋，甚至是一丝寒意。

兴奋在于，作为消费者，我们能以越来越低的价格，享受到以前不敢想象的技术和体验。寒意在于，作为行业观察者，我看到了技术碾压和规模效应结合后产生的恐怖力量。

比亚迪不再满足于做“销量冠军”。它正在利用自己的全产业链优势和巨大的规模，<span style="color: rgb(202,88,99); font-weight: bold;" >主动发起一场技术普惠的革命。</span>把高端配置快速拉低，把用户体验的门槛彻底踏平。

海狮05是一份宣言。它告诉所有人：新能源车的内卷，远未结束。好戏，才刚刚开始。

接下来，压力完全来到了竞争对手这边。你们，跟还是不跟？
