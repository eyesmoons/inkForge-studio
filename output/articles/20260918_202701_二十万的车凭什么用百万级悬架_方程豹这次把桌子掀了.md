# 二十万的车凭什么用百万级悬架，方程豹这次把桌子掀了

九月十六号那天，我盯着方程豹的发布会看了很久。说实话，看到价格出来的那一瞬间，我脑子里蹦出来的第一个念头是：小米SU7和Model 3的会议室里，今晚大概要加班了。

十八万九千九，你就能买到一台车长超过五米、零百加速跟跑车掰手腕、续航标到九百公里的中大型轿跑。这个价格放在两年前，你只能买到一台合资品牌的紧凑型燃油车，配置表寒酸得让人想哭。现在呢，方程豹直接把桌子掀了。

# 这不是一台普通的比亚迪

我知道很多人看到比亚迪三个字，脑子里第一反应还是网约车。但方程豹这个品牌，从诞生那天起就没打算走寻常路。之前的豹5和豹8，方方正正的硬派越野造型，摆明了是要跟坦克和牧马人抢饭吃。这次突然调转枪口，推出方程S和方程S GT两款轿车，而且直接杀进二十到三十万这个最血腥的价格带，意图太明显了。

<span style="color: rgb(202,88,99); font-weight: bold;" >方程豹要用跑车的设计语言，去降维打击家用轿车市场。</span>

你看方程S那个造型，跟Formula X跑车同源的设计，前脸那个锋豹之眼大灯，里面是双U形日行灯，外扩的前唇，车头四组贯通式风道。这些东西放在一台跑车上不稀奇，放在一台起售价不到十九万的轿车上，那就是赤裸裸的挑衅。风阻系数零点二二，什么概念？保时捷Taycan的风阻系数是零点二二，奔驰EQS是零点二零。方程S用二十万的价格，做出了百万级豪车的空气动力学水平。

车尾那个无限之环尾灯，点亮之后左右各两个菱形图案，晚上跟车的时候你一眼就能认出来。方程S是溜背设计，小鸭尾翘得特别高调。方程S GT更狠，后窗上面直接加了个扰流板，猎装车的线条从B柱往后一路延伸，那个姿态比很多标榜运动的欧洲车都要纯粹。

<span style="color: rgb(202,88,99); font-weight: bold;" >二十万的车，四十万的气场，这是方程S系列最不讲道理的地方。</span>

# 云辇-M才是真正的杀手锏

外观这种东西见仁见智，有人觉得帅有人觉得用力过猛。但云辇-M智能磁流变悬架这个东西，是实打实的技术壁垒。

我开过搭载云辇系统的豹5，那种底盘质感跟传统越野车完全不是一回事。磁流变液这个东西，简单说就是减震器里面的油液在磁场作用下能瞬间改变粘度。传统悬架的软硬调节靠阀门，反应速度是毫秒级。磁流变是物理特性层面的变化，响应速度也是毫秒级，但调节范围更宽，动态跟随能力更强。

<span style="color: rgb(202,88,99); font-weight: bold;" >云辇-M首搭在方程S上，这意味着二十万出头的价格，你就能买到目前市面上响应最快的主动悬架之一。</span>

官方说这套系统支持预瞄感知，能提前识别路面坑洼然后主动调整悬架软硬。这个功能我在奔驰S级上体验过，确实有用，过减速带的时候车身姿态控制得特别好。方程S把这个技术下放到二十万级别，属于不讲武德。而且它还支持OTA升级底盘算法，今天买的车，明年可能底盘性格就变了，这种玩法传统车企根本跟不上。

四驱版综合功率四百九十千瓦，什么概念？宝马M3 Competition的功率是三百七十五千瓦，奥迪RS4是三百三十一千瓦。方程S四驱版的动力比这些百万级性能车还要猛。当然电动车加速快是常识，但底盘能不能撑得住这么大的动力，才是关键。云辇-M加上漂移模式，方程豹显然在操控上下了大功夫。

# 九百公里续航，焦虑这个词可以删了

续航是电动车永远绕不开的话题。方程S最大续航九百公里，搭载第二代刀片电池。我知道有人会说CLTC续航打七折才是真实水平，但就算打七折，六百三十公里的实际续航也足够你从北京一口气开到青岛。

真正让我觉得有意思的是闪充技术。百分之十到百分之七十只用五分钟，百分之十到百分之九十七用时九分钟。这个数据如果实测能达标，那电动车最后的短板就被补上了。你在高速服务区上个厕所买瓶水的功夫，电就充得差不多了。

<span style="color: rgb(202,88,99); font-weight: bold;" >续航和补能这两件事，方程S一次性全给你解决了，而且解决得相当彻底。</span>

当然，闪充需要配套的充电桩。目前市面上支持这么大功率的桩还不多，这是现实问题。但技术先行的意义在于，当基础设施跟上之后，你的车不会成为瓶颈。这就跟五年前买五G手机一样，当时五G信号覆盖很差，但现在呢？

# 内饰和生态，学了小米但不止于小米

坐进车里，白黑双拼、绿灰双拼、紫黑双拼三种内饰配色，跟外观那种张牙舞爪的风格完全相反，走的是居家科技路线。悬浮式中控屏尺寸刚刚好，不会像某些品牌那样恨不得把电视机塞进去。二十六英寸的AR-HUD，帝瓦雷音响，零重力座椅带加热通风按摩，车载冰箱，一百二十八色氛围灯。这些配置堆在一起，放在合资品牌上至少是四十万起步的车才敢想。

但真正让我觉得方程豹想明白了的，是那个类似小米的选装配件模式。

中控屏两侧可以磁吸氛围灯，DIVA表盘能换头套，中控屏顶部可以加物理按键还能换键帽，按键功能可以自定义。甚至还有个磁吸圆钮，可以像遥控器一样拿在手里，移动着控制各种功能。最离谱的是能接入无弦吉他在车里K歌。

<span style="color: rgb(202,88,99); font-weight: bold;" >这套玩法明显是冲着年轻人来的，而且冲得很准。</span>

小米SU7为什么卖得好？因为小米太懂年轻人想要什么了。手机支架、物理按键、生态联动，这些细节让年轻人觉得这车是给自己造的。方程豹现在把同样的逻辑搬过来，而且做得更开放。PIN口、磁吸、螺纹三大接口开放出去，以后第三方配件商可以开发各种好玩的东西。这种生态一旦建立起来，用户粘性会非常可怕。

天神之眼B智驾系统，激光雷达加持，高速NOA和城区NOA都有，自动泊车也是标配。比亚迪在智驾这块起步不算早，但迭代速度很快。天神之眼这套系统已经在比亚迪多款车型上大规模铺开了，数据积累的速度是其他品牌比不了的。

# 小米SU7和Model 3真正的对手来了

二十到三十万这个价格区间，八月份销量最好的两台车是Model 3和SU7，分别是两万零七百八十七台和一万六千五百一十八台。Model 3的优势是极致的驾控体验和强大的品牌口碑，SU7的优势是科技感和性价比。

方程S系列的打法很清晰，用跑车设计语言吸引眼球，用云辇-M建立技术壁垒，用九百公里续航消除焦虑，用选装生态讨好年轻人。它没有明显的短板，而且在多个维度上都做到了同级领先。

<span style="color: rgb(202,88,99); font-weight: bold;" >十八万九千九的起售价，比Model 3后驱版便宜了三万，比SU7标准版便宜了两万六。</span>

这个定价策略让我想起当年比亚迪秦PLUS DM-i冠军版上市的时候，九万九千八的价格直接把合资紧凑型轿车打崩了。现在方程S用同样的逻辑打二十万级市场，能不能复制当年的奇迹？

我觉得概率很大。因为比亚迪的供应链成本控制能力，目前没有第二家车企能比。同样的配置，别人做出来要二十五万，比亚迪能做到二十万还有利润。这种成本优势转化成的价格优势，在消费者眼里就是实打实的诚意。

Model 3的品牌光环还在，SU7的流量效应也还在。但方程S的出现，让这个市场的竞争从两强相争变成了三足鼎立。对消费者来说，这是好事。对小米和特斯拉来说，压力是实实在在的。

# 说点实在的

我不是比亚迪的粉丝，我也从来不觉得哪家车企是完美的。方程S系列有没有问题？肯定有。比如那个可撕百变车漆，听起来很酷，但实际耐用性和后期维护成本是个未知数。比如磁吸配件生态，初期肯定不会有太多第三方产品。比如闪充技术，没有配套充电桩就是纸上谈兵。

但这些都不影响一个基本判断：<span style="color: rgb(202,88,99); font-weight: bold;" >方程S系列让二十到三十万新能源轿车市场的竞争，进入了一个新的阶段。</span>

以前大家比的是谁的屏幕大、谁的续航长、谁的加速快。现在方程豹把跑车设计、磁流变悬架、闪充技术、开放生态这些东西打包塞进一台二十万的车里，直接把竞争维度拉高了。

小米SU7上市的时候，很多人说它是保时捷平替。现在方程S来了，它想做的是把跑车的灵魂塞进家用车的躯壳里。

这件事能不能成，最终还是要看销量。但至少从产品力来看，方程豹这次是认真的。九月十六号之后，想买二十万级新能源轿车的人，绕不开方程S这个选项了。

至于小米和特斯拉怎么接招，我们等着看。
