# DeepSeek V4 把底牌掀了：开源1.6T，联手华为，三个月清退旧模型

今天上午，我刷到 DeepSeek V4 的发布稿，第一反应不是兴奋，是愣住。

1.6T 参数，开源，跟华为芯片深度绑定，三个月后旧版 API 全部停用。这不是一次常规迭代，这是一场针对整个 AI 生态的“拆墙运动”。DeepSeek 选择在 2026 年 4 月 29 日亮出这张牌，时间点卡得极准——正好在 OpenAI 和 Google 调整完定价、国内几家大厂还在纠结要不要全面开放的时候。

你可能会问，一个开源模型而已，至于这么大动静？但如果你真看过那份发布稿，就知道这次不一样。

## 开源不是施舍，是进攻

以前提到开源模型，默认就是“残血版”。参数缩水、能力打折，说白了就是大厂喂给开发者的“免费试用装”。你用可以，真要干点正经事，还得回去买闭源 API。

DeepSeek V4 直接把 1.6T 参数全量开源。这个数字意味着什么？目前已知的闭源最强模型，参数规模也就这个量级。DeepSeek 把压箱底的东西甩出来，不收钱，不限次，你随便下。

这不是做慈善，是战略。当闭源模型还在用“等待列表”和“按 token 收费”收割开发者时，DeepSeek 说：代码就在这，你自己跑。你跑得好，是你本事；跑不好，我还能帮你优化。这种姿态天然就把开发者拉到了自己这边。你想想，一个帮你省下每年几十万 API 费用、还让你拥有完整控制权的模型，和另一个每年涨价 15%、随时可能改条款的模型，你选谁？

我注意到一个细节：发布稿里特别强调“开源协议友好”。这句话不是白写的。之前很多所谓开源模型，协议里埋了各种坑——商用要授权、二次发布要分成、甚至改了代码还得把版权回馈给原公司。DeepSeek 这次把协议做干净了，等于直接告诉企业：你放心用，我不碰你的数据，不占你的股份。

这是把闭源模型最硬的底牌——数据安全和成本控制——直接抽走了。

## 联手华为芯片，打的是算力牌

如果说开源是“拆墙”，那跟华为芯片合作就是“修路”。

DeepSeek 宣布与华为芯片深度适配，降低国产算力门槛。翻译一下：你不用再去抢 H100，用华为的芯片一样能跑 V4，甚至跑得更好。

这是个大杀器。现在国内做 AI 应用的公司，最头疼的不是模型能力，是算力成本。一张 H100 被炒到几十万，还要看有没有渠道拿货。很多初创公司融的钱全砸在算力上，最后活活被成本拖死。

DeepSeek 跟华为芯片合作，等于在现有算力体系之外开了一条新路。你不需要跟大厂抢 H100，不用忍受云厂商的天价租用费，用国产芯片就能跑通 1.6T 的模型。这个门槛降低的幅度，不是 10% 或 20%，是数量级的。

有人可能会质疑：华为芯片的算力效率和生态成熟度，能跟英伟达比吗？我承认，差距还在。但 DeepSeek 做的是“深度适配”，不是简单移植。它在算法层面做了大量针对华为芯片的优化，比如算子重写、显存管理调整、通信模式定制。把这些功夫做到位，实际推理效率不会差太多。

更重要的是，这条路径一旦跑通，整个国产 AI 产业链就活了。芯片厂商有了标杆应用做验证，云厂商可以推出性价比更高的推理服务，开发者在选择硬件时不再是被动接受。DeepSeek 等于在告诉市场：算力不是只能走一条路。

## 三个月迁移期，是结束也是开始

发布稿里有一个让很多开发者心头一紧的数字：三个月。

旧版 deepseek-chat 和 deepseek-reasoner 将在 7 月 24 日停用，所有开发者必须在三个月内完成模型迁移，适配 V4-Flash 模式。

三个月，说长不长，说短不短。对于已经基于旧版 API 构建了完整业务流的团队来说，这个迁移窗口确实有点紧。你需要重新测试模型输出质量，调整 prompt 写法，可能还要修改后处理逻辑。如果你用的是 deepseek-reasoner 做复杂推理任务，迁移成本会更高。

但我得说句实话：这恰恰是 DeepSeek 够决断的表现。

很多公司做版本升级，总想着“平滑过渡”，结果新老版本并行大半年，开发者懒得迁移，老代码越来越烂，最后新模型的能力根本落不了地。DeepSeek 选择硬性截止日期，等于逼着生态完成一次“洗牌”。你如果还守着旧版，三个月后你的应用会直接崩溃。这种痛感会让开发者在第一天就开始规划迁移，而不是拖到最后一周。

而且 V4-Flash 模式不是简单的新瓶装旧酒。根据发布稿的描述，Flash 模式在推理速度和上下文长度上都做了大幅提升。完成迁移之后，开发者实际获得的体验是质的飞跃。所以三个月不是惩罚，是强制升级。

我建议做迁移决策的人注意一个时间窗口：5 月到 6 月是测试和适配的黄金期，别拖到 7 月。现在就开始拉分支、跑对比、压测。如果你团队里的核心应用依赖 DeepSeek，7 月 24 日之前没完成迁移，损失的可能不是几天的停机时间，而是用户的信任。

回到最初的问题：DeepSeek V4 到底想干什么？

它想做的事情很简单：用开源撕掉闭源模型的傲慢，用国产芯片打碎算力垄断的枷锁，用硬性升级清洗掉生态里的惰性。这三件事放在一起，不是一次产品发布，是一次对 AI 产业秩序的重新定义。

我见过太多模型发布时吹得天花乱坠，最后落地时一地鸡毛。但 DeepSeek 这次不一样。它给了你代码，给了你硬件路径，给了你明确的迁移时间表。剩下的，就是你能不能接住这张牌。

从实践中来，到系统中去。
