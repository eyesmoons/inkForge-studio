# 华为Pura X Max秒罄背后：谁在花一万买折叠屏手机？

2026年04月25日早上10点08分，华为Pura X Max正式开售。

然后，秒罄。

全色系、全内存版本，一个不剩。线下门店的排队照片在朋友圈疯传，有人抱怨自己根本没来得及点下“提交订单”。这不是华为第一次搞出这种场面了。

说实话，一台起步价10999元的手机，卖到这个程度，你很难不去想一个问题：到底是谁在买？

别急着回答“有钱人”，这个答案太敷衍了。

我们先看一组数据。华为折叠屏市场份额已经超过70%。这是什么概念？意味着每卖出去三台折叠屏手机，就有两台是华为。而Pura X这个系列，上一代已经卖出超过150万台。

150万台，均价一万块。这个市场规模，早就不是一个“小众玩物”能解释的了。

Pura X Max这次打出的牌，叫“大阔折”。7.7英寸的内屏，比例是√2:1。你可能对这个数字没感觉，但拿到手里你就明白了——它比传统的折叠屏更宽，展开之后更像一本真正的书。视频、文档、电子书，体验完全不一样。

我直接说结论：华为不是在造手机，而是在重新定义“移动屏幕”。

你想想，从iPhone 4的3.5英寸，到现在的7.7英寸，屏幕越来越大，本质上是人类对信息密度的渴求。但手机尺寸是有物理极限的，折叠屏就是打破这个极限的唯一方案。而华为在这个赛道上的积累，已经不是追不追得上的问题了。

另一个值得说的点，是伴随式AI“小艺”。

业界首个，这个名头不是白给的。它不是一个你呼之即来挥之即去的语音助手，而是一个真正理解你使用场景的AI。你翻到哪一页，它就知道你需要什么；你在读哪段文字，它就能帮你提炼要点。

我知道有人会说，AI助理都是噱头。但你仔细想，如果这个AI真的能记住你的习惯，预测你的需求，那它的价值远高于参数表上的任何一个数字。华为赌的是，未来的手机核心竞争力不是硬件，而是智商。

你可能会问，卖这么贵，值吗？

我觉得这个问题本身就问错了。华为Pura系列的定价逻辑，从来不是“堆料-定价”的性价比路线。它的逻辑是：我给你一个你之前没有的东西，你愿意为这个“没有”付费。

想想当年的Mate X，第一款折叠屏，黄牛价炒到两万，照样有人抢。为什么？因为它在当时是独一无二的。Pura X Max也一样——大阔折形态，目前只有它一家。你买不到，所以它贵，也合理。

还有一件事值得注意。华为这次一口气上了五种配色，四档内存组合，从12+256起步。这是一个很聪明的策略。它没有把高配版本当成“尊享款”来卖，而是让每个价位的人都能找到自己的选择。你预算紧张的，12+256够用；你要极致体验的，顶配等着你。

这不像一个高傲的品牌，更像一个饿了很久的猎人。

回到开头那个问题：到底谁在买这些万元折叠屏？

我的判断是三类人。

第一类，是华为生态的老用户。他们用着华为手机、手表、平板、耳机，换机只在华为内部选。Pura X Max是他们能买到的“最好的华为手机”，没有之一。

第二类，是商务人士和中产阶层。对他们来说，一万块不是小钱，但也不是不可承受的。他们要的是一台能让自己在会议桌上、高铁上、咖啡馆里显得专业且不费力的设备。折叠屏的大屏体验，正好满足这个需求。

第三类，是数码发烧友。他们不差钱，他们差的是“新鲜感”。Pura X Max的大阔折和伴随式AI，就是他们愿意掏钱的理由。

这三类人，加起来，就是150万台的销量和70%的市场份额。

别以为折叠屏只是“有钱人的玩具”。它正在变成一个真实的市场，一个华为已经牢牢占据领导地位的市场。而Pura X Max的秒罄，只不过是这个趋势的最新注脚。

不只看参数，更看趋势。
