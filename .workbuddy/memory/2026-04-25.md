## 领域网站爬取深度修复
- **用户反馈**：全自动发布日志中看不到领域网站搜索信息
- **根因排查**（3层问题）：

  2. 重写 `_fetch_domain_news()`：先读数据库 ref_websites → 再读 domains_config.json 补充 → 都没有时用搜索引擎补充
  3. 所有领域统一逻辑，去掉 "科技" 领域的特殊分支（`_fetch_tech_news_legacy` 不再被调用）
  4. 所有日志加 `[领域]` 前缀，让用户明确看到爬取过程
  5. 改造 `_ensure_default_domains()`：创建系统领域时从 `domains_config.json` 同步预置网站到 `ref_websites`
  6. 更新现有数据库：科技(4站)、汽车(13站)、财经(3站)、美食(2站)、旅游(2站) 已同步

## AI 排版：小标题丢失问题修复
- **用户反馈**：AI 排版后小标题（##）消失了，文章没有按主题色排版
- **关于主题色**：AI 排版只优化 Markdown 文本（语言/结构），不涉及 HTML/CSS 主题色。主题色在 MD→HTML 转换（`markdown_to_wechat_html`）时通过 CSS 注入，和 AI 排版是两个独立步骤，流程正常
- **小标题丢失根因**：
  1. 默认写作 prompt（`build_article_prompt`）只说"主体 3~4 个自然段落"，没要求用 `##` 小标题 → LLM 生成纯段落文章
  2. AI 排版 prompt 说"添加或优化小标题"但不够强硬，部分 LLM 没加或反而删除了已有小标题
- **修复**：
  1. 默认写作 prompt + 自定义写作 prompt：输出格式中明确要求"必须包含 2～4 个 ## 小标题来划分段落层次"，结构参考中说明用 `##` 分段
  2. AI 排版 prompt（`ai_writer.py` + `web_app.py` 两处）：第 4 条改为"必须保留原有所有 ## 小标题，不能删除；如果没有则必须添加 2～4 个"
