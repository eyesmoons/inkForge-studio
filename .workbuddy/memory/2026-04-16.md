# 2026-04-16 工作日志

## 封面制作 + 素材库功能开发

### 新增功能
1. **封面生成记录表 (cover_generations)** - 支持用户隔离，记录AI生成封面的prompt、filename、model_name等
2. **素材库表 (material_library)** - 支持用户隔离，可收藏封面制作生成的图片，也可手动上传
3. **素材分组表 (material_groups)** - 支持用户隔离，素材可分组管理
4. **素材库模块 (modules/material_library.py)** - CRUD接口 + 分组CRUD + 上传 + 收藏去重
5. **素材库前端页面** - 网格展示、分组侧栏、标签筛选、搜索、上传、移动分组、收藏/删除
6. **封面制作前端** - 收藏时传source_id，历史记录显示"已收藏"标记和状态
7. **web_app.py** - 素材库API + 分组API + 上传API + 移动分组API + 收藏去重提示
8. **所有13个页面侧边栏添加素材库菜单**
9. **database_schema.sql更新**

### 技术要点
- AI图像生成模型从glm-image切换为智谱CogView-4
- 封面制作和素材库均通过user_id实现用户隔离
- 素材收藏时复制图片文件（cover_→mat_前缀），上传图片用upload_前缀
- cover_generations.is_collected标记是否已收藏，避免重复收藏
- 收藏去重：同一用户同一源文件不可重复收藏，后端返回友好提示
- 素材分组：左侧分组侧栏，支持创建/重命名/删除分组，素材可移动分组
- 上传支持拖拽和点击，限制10MB，支持PNG/JPG/GIF/WebP/BMP
