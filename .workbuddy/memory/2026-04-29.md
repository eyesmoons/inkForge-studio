## 选题时效性修复（auto_selector.py）
问题：全自动发布和自动选题选出的内容过时
根因排查发现 5 层叠加问题：
1. Bing Search API 缺少 freshness 参数 → 加 `freshness=Week`
2. DuckDuckGo HTML 缺少 df 参数 → 加 `df=w`（一周内）
3. RSS（36氪、IT之家）不解析 pubDate → 新增 `_parse_rss_pubdate()` 解析并过滤 7 天以上旧内容，同时将日期注入 snippet 便于后续过滤
4. `_filter_recent_results` 把 undated（热搜等）全部丢弃 → 改为 recent + undated 合并返回，只丢弃有日期但过旧的内容
5. AI 整理提示词时效约束太弱 → 传入 cutoff_date（3天前），要求"只选近3天内新闻，超过3天的旧闻一律排除"
