# 2026-07-12 工作日志

## 写作技能管理功能（新增）
- 新增 `writing_skills` 数据库表（user_id, name, description, prompt_content, category, is_active, sort_order）
- DB层：`UserDB` 新增 `get_user_skills()`, `get_skill_by_id()`, `create_skill()`, `update_skill()`, `delete_skill()` 方法
- API层：`/api/skills` GET/POST + `/api/skills/<id>` PUT/DELETE，标准认证模式
- 前端页面：`skill.html`，卡片网格布局，支持新建/编辑/删除/启停，内置5个快捷模板
- 侧边栏：所有14个HTML页面（除login）都添加了"🎯 写作技能"导航项（资源管理分组）
- 写稿页集成：`write.html` 新增写作技能下拉选择器，`common.js` 新增 `loadWriteSkills()` 函数
- 生成流程集成：
  - `/api/generate` 接收 `skill_id`，加载技能提示词后传给 `generate_article(skill_prompt=...)`
  - `/api/auto` 同样支持 `skill_id`，传给 `run_auto_pipeline(skill_prompt=...)`
  - `ai_writer.py` 的 `build_article_prompt()` 新增 `skill_prompt` 参数，优先级最高（覆盖 custom_writing_prompt）
  - `main.py` 的 `run_auto_pipeline()` 新增 `skill_prompt` 参数透传
- 优先级链：skill_prompt > custom_writing_prompt > config_prompt.json > 默认高质量提示词
