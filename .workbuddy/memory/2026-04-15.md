## 修复

### 1. hotrank.html 路由缺失（404）

- **问题**：访问 `/hotrank.html` 返回 404，原因是 `web_app.py` 中遗漏了对应路由
- **修复**：在 `web_app.py` 的 `profile()` 路由后追加了 `/hotrank.html`、`/hotrank.js`、`/hotrank.css` 三条路由
- **操作**：需重启 Flask 服务生效

### 2. today_in_history.html 500 错误

- **问题**：`get_current_user()` 调用缺少 `session_id` 参数
- **修复**：将 `get_current_user()` 改为 `get_current_user(session_id)`

### 3. today_in_history.html 配色适配

- **问题**：页面使用浅色主题，与系统深色主题不一致
- **修复**：更新 `today_in_history.css` 使用 `--bg`、`--bg2`、`--bg3`、`--text`、`--text2`、`--accent`、`--border` 等 CSS 变量，统一为深色主题

### 4. 热搜榜接口修复

- **微博**：改用 `s.weibo.com/top/summary` 热榜页面解析（原接口 403，weibo.cn 无数据）
- **知乎**：改用知乎日报 API `news-at.zhihu.com/api/4/news/hot`，避免 401 认证
- **豆瓣**：改用小组热门话题 HTML 解析，原接口 404
- **IT之家**：改用首页热榜解析，原接口 500
- **腾讯新闻**：更换为新接口 `r.inews.qq.com/gw/event/hot_ranking_list`

### 5. 历史上的今天数据修复

- **问题**：百度 API 数据结构为 `{"04": {"0415": [...]}}`，代码直接查找 `data["0415"]` 导致找不到数据
- **修复**：添加 `month_key` 层级，正确解析嵌套结构

## 新增功能：每日热搜榜

新增了完整的每日热搜榜模块，包括以下内容：

### 文件
- `modules/hotrank.py` — 后端抓取逻辑，支持15个平台
- `web_static/hotrank.html` — 独立页面（引用 hotrank.js 和 hotrank.css）
- `web_static/hotrank.js` — 前端独立JS（Tab切换、数据加载、渲染）
- `web_static/hotrank.css` — 专属样式（卡片网格、金银铜牌排名、加载动画）

### 支持平台（按顺序）
微博、百度、今日头条、哔哩哔哩、知乎、抖音、**微信搜索**、腾讯新闻、网易新闻、澎湃新闻、36氪、稀土掘金、IT之家、少数派、豆瓣

### API 路由
- `GET /api/hotrank/<platform_id>` — 获取单个平台热榜
- `GET /api/hotrank` — 获取平台列表

### 侧边栏
已在所有9个HTML页面的侧边栏"工作台"后面插入"🔥 每日热搜榜"入口。

### 修复：微信搜索热搜抓取
- **问题**：`fetch_wechat_search()` 函数通过爬取搜狗微信首页HTML无法获取热搜数据
- **修复**：改用搜狗热词API接口 `https://www.sogou.com/suggnew/hotwords`，直接解析JSONP格式数据
- **结果**：可正常获取约46条热搜，展示前20条

### 修复：热搜榜链接和标题问题

- **知乎**：API返回的 `url` 是API端点（`http://news-at.zhihu.com/api/2/news/xxx`），打开显示JSON。修复：提取文章ID拼接成 `https://daily.zhihu.com/story/{id}`
- **IT之家**：手动拼接链接 `https://www.ithome.com/0/{newsid}.htm` 返回404，因为newsid需拆分（如939246→939/246）。修复：优先使用API返回的 `url` 字段（如 `/0/939/246.htm`）
- **少数派**：标题显示异常。原因：页面无 `title`/`alt` 属性，标题在 `<span>` 文本中。修复：从 `<a>` 内部 `<span>` 文本提取标题
- **豆瓣**：页面结构变更，标题从 `<a>` 的 `title` 属性变为 `<h3><a>标题文本</a></h3>`。修复：更新正则匹配新模式
