### 统一爆款标题生成提示词

**问题**：自动选题、一键写稿、链接改写、AI小助手都涉及爆款标题生成，但提示词分散在多个文件中。

**解决方案**：
1. 创建新模块 `modules/title_generator.py`，包含：
   - `TITLE_GEN_PROMPT` - 统一的爆款标题生成提示词
   - `generate_title()` - 生成单个标题的函数
   - `generate_titles()` - 生成多个标题（用于AI小助手）
   - `suggest_title_from_topic()` - 从选题生成标题

2. 修改 `modules/article_rewriter.py`：
   - 导入统一模块：`from .title_generator import TITLE_GEN_PROMPT, generate_title as _generate_title_v2`
   - 删除原来的 `_TITLE_GEN_PROMPT` 和 `generate_title()` 定义
   - 保留 `generate_title` 别名指向统一模块（向后兼容）

3. 修改 `modules/ai_assistant.py`：
   - 更新导入路径从 `article_rewriter._TITLE_GEN_PROMPT` 改为 `title_generator.TITLE_GEN_PROMPT`

**架构说明**：
```
modules/title_generator.py (统一的标题生成模块)
    ├── TITLE_GEN_PROMPT (提示词)
    ├── generate_title() (单标题)
    ├── generate_titles() (多标题)
    └── suggest_title_from_topic() (选题标题)

modules/article_rewriter.py
    └── generate_title = _generate_title_v2 (别名指向统一模块)

modules/ai_assistant.py
    └── from title_generator import TITLE_GEN_PROMPT

web_app.py
    └── from article_rewriter import generate_title (仍然有效，通过别名)
```

**文件变更**：
- 新增：`modules/title_generator.py`
- 修改：`modules/article_rewriter.py` (删除重复代码，使用统一模块)
- 修改：`modules/ai_assistant.py` (更新导入路径)
